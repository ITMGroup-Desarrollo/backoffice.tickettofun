# Backoffice

It's an administration site for manage cruises, tours, allotments, schedules of arrives.

## Requirements

 - PHP 7.2 or higher
 - User database conection to `itm_core`
 
## Code styles
 
 - [PHP style guide](https://codeigniter.com/user_guide/general/styleguide.html)
 - [Javascript standard](https://standardjs.com/)
 
## Built with
